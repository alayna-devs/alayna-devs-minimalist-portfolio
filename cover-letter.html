Career Goals

Software Engineer

I’m a software developer and software engineer driven by curiosity and the desire to understand how systems actually work beneath the surface. My path into programming started with exploring how applications communicate with services and data, and that curiosity has grown into hands-on experience across mobile, cloud, and web development. While I’ve worked with several areas of software engineering, my current focus is full-stack web development, building modern web applications using tools like React, JavaScript/TypeScript, Python, and cloud services.

Earlier in my development experience, I worked in an environment that involved Android development using Java and Kotlin, where I contributed to application features, addressed bugs, and supported integrations that relied on AWS infrastructure. Working in that space gave me practical exposure to maintaining real software systems, understanding how mobile applications communicate with backend services, and collaborating within structured development workflows. It also strengthened my debugging skills and taught me how important reliability and clear architecture are in production applications.

Outside of that role, I continue building projects that allow me to explore technologies in more depth. One project I developed is a React-based meal discovery application that integrates with TheMealDB API, allowing users to search for meals, view recipe details, and explore new dishes through a dynamic interface. The project focuses on component-based UI design, managing application state, and working with asynchronous API data in a clean and responsive frontend. Building projects like this helps me experiment with modern web practices while improving my ability to design software that is both functional and user-friendly.

More recently, I’ve been working with Python to develop a log and event monitoring tool designed to process and analyze information from data pipelines. The project focuses on parsing logs, filtering events, and transforming raw data into structured outputs that can be inspected or monitored more easily. It’s been a great way to deepen my understanding of data flow, scripting, and how backend processes support larger software systems.

I’m also currently pursuing a Computer Science degree at Western Governors University (WGU). Through my studies, I’m building a deeper foundation in areas such as data structures, algorithms, operating systems, and software engineering principles. While my projects give me hands-on experience with real tools and frameworks, my academic work strengthens the theoretical understanding behind them. This combination helps me approach problems more thoughtfully, design cleaner solutions, and understand how systems scale beyond a single application.

What motivates me most as a developer is the constant opportunity to learn. Technology evolves quickly, and I enjoy staying curious—exploring documentation, experimenting with tools, and building projects that push my understanding forward. I’m especially drawn to modern web development because it sits at the intersection of many systems: frontend interfaces, backend services, APIs, and cloud infrastructure.

As I continue growing as a developer, my goal is to contribute to teams where I can build meaningful software, solve practical problems, and keep improving both my technical and collaborative skills. I bring persistence, adaptability, and a genuine interest in learning new technologies—qualities that help me quickly understand systems and contribute to building reliable, maintainable applications.
