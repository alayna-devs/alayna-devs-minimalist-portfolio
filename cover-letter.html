Software Engineer Cover Letter

I’m a software engineer/software developer driven by curiosity and the desire to understand how systems actually work beneath the surface. My path into programming began while exploring how games were built using the scripting language Lua, which sparked a long-term interest in software development and application design. Since then, that curiosity has grown into hands-on experience across mobile, cloud, and web development environments. Today, my primary focus is full-stack web development, building modern web applications using technologies such as React, Next.js, Tailwindcss, JavaScript, TypeScript, Node.js, Express.js, Python, and cloud services.


I am currently pursuing a Computer Science degree at Western Governors University (WGU), where I am strengthening my foundation in data structures, algorithms, operating systems, mathematics, and software engineering principles. This academic work helps reinforce the theoretical understanding behind the tools and frameworks I use in projects. Alongside my studies, I build practical applications such as a React-based meal discovery application integrating the TheMealDB API. The project focuses on component-based UI design, managing application state, and working with asynchronous API data to create responsive and user-friendly interfaces.


My earlier professional experience includes roles in Android application development and cloud infrastructure. As an Android App Developer using Kotlin and Android Studio, I contributed to application features, resolved bugs, and supported integrations with backend services that provided dynamic data to the application.

In a separate role as an AWS Cloud Engineer, I worked with AWS services to support cloud-based CRM systems in Java, including managing customer data within DynamoDB and assisting with system migrations to AWS infrastructure. This experience also exposed me to development workflows involving Docker, SQS, and CI/CD pipelines, strengthening my understanding of production systems and scalable cloud architectures.


I’m particularly motivated by the constant opportunity to learn within software development and the challenge of building systems that solve real problems. As I continue growing as a developer, my goal is to contribute to teams building meaningful software, solving practical problems, and delivering reliable, maintainable applications. I bring persistence, adaptability, and a genuine interest in learning new technologies, and I would welcome the opportunity to further discuss how my skills could contribute to your team.
